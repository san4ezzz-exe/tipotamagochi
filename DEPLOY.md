# 🚀 Инструкция: Как запустить NeuroPet в Telegram 24/7 (Бесплатно)

Этот проект упакован в единый **Multi-stage Dockerfile**, который собирает React-фронтенд и запускает FastAPI-бэкенд на одном порту. Это означает, что для работы 24/7 нужен всего **один бесплатный сервис** и **одна постоянная ссылка**.

---

## ⭐️ Способ 1: Бесплатный хостинг Render.com (Самый простой, без оплат)

### Шаг 1. Загрузи проект на GitHub
1. Перейди на [github.com](https://github.com) и создай новый репозиторий (например, `neuropet-app`, выбери `Public` или `Private`).
2. Загрузи файлы проекта:
   * **Вариант А (через сайт):** Нажми кнопку **«Upload files»** на странице репозитория и перетащи все файлы из папки `project2` (кроме `node_modules` и `venv`).
   * **Вариант Б (через GitHub Desktop):** Открой [GitHub Desktop](https://desktop.github.com/), нажми `Add Existing Repository`, выбери папку `project2` и нажми `Publish Repository`.

---

### Шаг 2. Развертывание на Render.com (Займет 2 минуты)
1. Зарегистрируйся на [Render.com](https://render.com) (можно войти через GitHub в один клик).
2. Нажми кнопку **«New +»** в правом верхнем углу $\rightarrow$ выбери **«Web Service»**.
3. Подключи свой репозиторий с GitHub (`neuropet-app`).
4. Заполни базовые настройки:
   * **Name:** `neuropet-ai-lab` (или любое другое имя).
   * **Region:** Frankfurt (Европа, минимальный пинг).
   * **Environment:** `Docker` (Render автоматически найдет наш `Dockerfile`).
   * **Instance Type:** `Free` (бесплатно навсегда).
5. Нажми кнопку **«Deploy Web Service»** внизу страницы.
6. Подожди 2–3 минуты, пока соберутся фронтенд и бэкенд. В логах появится надпись:
   `Application startup complete. Uvicorn running on http://0.0.0.0:8000`.
7. В верхней части экрана Render выдаст тебе постоянную ссылку, например:
   👉 `https://neuropet-ai-lab.onrender.com`

---

### Шаг 3. Подключение к Telegram-боту через @BotFather
1. Открой Telegram и найди бота **[@BotFather](https://t.me/BotFather)**.
2. Создай бота (если еще не создал):
   * Напиши `/newbot`, укажи имя (`NeuroPet AI Lab`) и юзернейм (например, `my_neuropet_ai_bot`).
   * Сохрани полученный токен.
3. Добавь кнопку открытия приложения:
   * Отправь команду `/setmenubutton`.
   * Выбери своего бота.
   * Отправь ссылку из Render.com (например, `https://neuropet-ai-lab.onrender.com`).
   * Напиши название кнопки: `Играть 🚀` (или `NeuroPet 🧠`).
4. **Готово!** Теперь бот работает **24/7 автономно**. Компьютер можно выключать — игра будет открываться у любого студента с телефона в любое время!

---

## 🐳 Способ 2: Запуск на своем VPS-сервере (Docker Compose)

Если у тебя есть свой виртуальный сервер (Ubuntu / Debian):
1. Скопируй файлы проекта на сервер.
2. Запусти команду:
   ```bash
   docker compose up -d --build
   ```
3. Приложение поднимется на порту `8000` и будет работать в фоне с автоматическим перезапуском при перезагрузке сервера.
